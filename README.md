# 一叶问仙 · 仙缘纪 v6.1.0

面向 iPhone Safari 的东方神话抽卡与五人队伍游戏。资源无限，无充值；对手是明确标注的动态机器人，无需账号。生成的水墨矿彩角色与洞天场景、卷轴与金边界面均为本项目美术；采用仙侠游戏常见的养成、洞府和阵容机制，并未复制所参考游戏的素材、代码或完整数值。

## 下载与更新

[完整静态部署包](releases/one-leaf-web.zip)。下载 raw 文件、解压后完整覆盖原网站目录，不能只上传 index.html。支持 HTTPS 网站根目录或子目录，更新后顶部显示 **神府纪 · v6.1.0**。已有缓存可从菜单选择“保存并更新版本”；同目录 play.html 为内嵌资源的备用入口，不注册 Worker。

请保留原网址、浏览器和网站数据。GitHub 提交、开发环境发布均不等于更新你的现有网站；需要单独部署新包。首次完整缓存后可离线游玩。iPhone 可通过 Safari 分享菜单添加到主屏幕。

## 先保护已有进度

此前版本有一个明确缺陷：存档解析失败后，会保存默认新号覆盖主存档。v5 修复为先恢复有效备份；若无有效备份则暂停写入并保留原件，不能自动重置。

- 沿用 `one-leaf-squad-v3` 主存档键，兼容 v3/v4/v5/v6 阵容存档，英雄 ID、等级、星级、重复卡、阵位及卡池进度保留。新版神话姓名替换旧虚构姓名，不会重新抽取或删除已有卡牌。
- 维护本机最近快照，并额外写入 IndexedDB 独立数据库。读取时选择时间最新的有效存档，支持主存档缺失或损坏后的自动恢复；多窗口写入执行比较检查。
- **菜单 → 查看与恢复历史快照** 可查看旧版恢复备份与新快照，确认后接续；也支持导入、导出 JSON。若旧版本已覆盖进度，且旧恢复副本仍在此浏览器，可能在此找回。没有任何备份的数据无法凭空恢复。
- **申请浏览器持久存储** 由浏览器决定是否授予；页面会显示保存状态。关闭数日不会主动清空英雄、队伍、历练或仙府，只刷新每日和每周活动。
- 本机双存储不是云备份。清除整个站点数据、设备丢失、更换网址、无痕模式或浏览器清理全部存储，仍可能造成丢失。重要构筑请定期导出 JSON；没有账号服务器，不能承诺上述情形自动找回。
- v1/v2 单人游戏存档保留原件，将境界折为初始五人等级（最高20），并记录旧摘要；单人装备不直接变成团队装备。

## 72 位有出处的东方神仙

云阙、月华、山海三阵营各 24 位，每营均有御守、剑修、术法、医仙和影袭，均有 R/SR/SSR/UR。人物来自《西游记》《封神演义》《山海经》《淮南子》、八仙传说及道教/民间神祇传统。人物详情展示具体出处和简介；身份与传说版本有别时作说明。阵营、职业、技能、品质为游戏设计，并非原典神祇等级或宗教分类。

完整名录见 [HEROES.md](HEROES.md)。英雄详情提供来源、技能、属性、等级与觉醒说明。图鉴支持阵营、职业、品质和已拥有筛选。

## 卡池与品质

- 基础概率：R 灵品 60%，SR 仙品 30%，SSR 神品 8%，UR 道品 2%。品质属性系数依次为 1、1.10、1.22、1.34；不以付费获得。
- 六池：常驻、哪吒 UP、新手、云阙、月华、山海。阵营池只出对应阵营，各品质内等概率。
- 10 抽内 SR 或以上，50 抽内 SSR 或 UR，150 抽内 UR。连续 40 抽没有 SSR/UR 后，高阶概率每抽上升 6 个百分点；50 抽时为 100%。高阶通常按 80% SSR / 20% UR 分配，UR 硬保底优先。
- SSR/UR 重置 50 抽计数，只有 UR 重置 150 抽计数；SR 及以上重置 10 抽计数。每池计数独立，单抽和十连共享，旧版 50/10 保底迁移，新增 UR 计数从零开始。
- 哪吒 UP：SSR 中 50% 为哪吒，歪后下个 SSR 必为哪吒。UR 不消耗此保证。新手池限 20 抽，第10抽为 SSR 或 UR；其他池无限抽。

## v6：所有玩法服务抽卡

- 英雄抽卡直接展示两排十张结果，无翻牌或等待动画；结果立即保存。召唤首页可切换英雄、神兵与法宝入口。
- 72 位英雄立绘和阵营标签分离。升星展示五颗命星、攻击/气血/防御前后对照、绝技增伤和所需重复数量；每星绝技伤害额外 +3%。
- 神兵池与法宝池各 12 件，R/SR/SSR/UR 基础概率 50/35/12/3%；20 抽内 SSR+，80 抽内 UR，独立保底。每件器物有独立的攻击/气血/防御权重与绝技后触发的器灵技能；每位英雄各装备一件，同名多件可以分给多人。具体数值在卡牌详情与替换对比中显示。
- 12 类联动：灼烧、破绽、护盾、治疗、追击、聚灵、净化、队友充能、自愈、破盾、雷击追加、残血处决。治疗绝技能净化灼烧；护盾吸收伤害，标记与灼烧放大队友伤害。
- PK、历练、登塔获胜：立即入库英雄十连、随机器物一件及天命印一枚。仙府探索完成赠送英雄十连和天命印。失败不扣资源，可免费调整阵容继续挑战。
- 通天塔不设置设计层数上限，不随周重置。每层获胜均给上述奖励；每 5 层额外 SSR，每 10 层改为额外 UR。采用 24 种敌阵轮换，等级和星级逐步增加至已有培养上限。不是无限膨胀数值；高层继续轮换阵容。
- 声望是永久解锁进度：100 解锁心愿，300 解锁天命自选。心愿只在池内包含该英雄且抽中其品质时生效，先以 50% 概率定向，未命中仍按原池抽取；不改变品质概率、不干扰哪吒 UP 保证。10 枚天命印自选任意 SSR/UR；重复用于升星。
- v5 升级保留英雄、六池保底、仙府及既有竞技对手分数；旧本周塔层转为永久层数，新增对手用初始分加入。每日/每周奖励仍单独刷新。

## v6.1：专属技能与本命器物

修复灶神治疗职业无法触发灼烧的问题：绝技明确执行全队治疗、敌方最低血量者灼烧、弱势队友护盾。每位英雄不再只使用五职业共用绝技；72 套独立配置均在测试中实际施放。例：哪吒连续三击附灼烧，杨戬先破盾再穿透攻击后排，嫦娥群疗并护盾后排，伏羲单体攻击、群体标记并自护盾。布阵页提供离火、太虚、幽冥三种可采用的构筑示例，缺少英雄时显示抽取目标。

24 件器物各有独立绘制的图标、属性权重和技能序列，五职业均可触发。六套二仪：离火、破军、玄武、长生、诛邪、太虚；同一英雄装备同套装神兵与法宝后生效，不跨英雄拼套。每件器物提供可搭配的另一槽器物名单。

- 装备流程：英雄 → 本命器物卡槽 → 按套装筛选 → 查看技能及替换前后属性 → 确认装备。可卸下，库存数量约束继续有效。对比为个人基础属性＋装备，不含全队羁绊和仙府。
- 培养：免费升至 20 级；每级使器物基础属性加成提高 2%，每精炼一星另加 10%，两者相加计算。精炼还使器物伤害/治疗/护盾/破盾数值每星提升 10%，不延长状态、不增加灵力点数，不增强套装固定效果。
- 同名累计抽取 2/4/7/11/16 件解锁精炼 1–5 星，不消耗副本；同名器物共享培养，给重复抽卡提供长期目标。
- 兼容 v6 器物库存、装备、保底；新培养默认 1 级 0 星。当前存档若培养字段损坏，会拒绝读取并尝试备份，不会静默把培养归零。
- 灼烧与回春分别按目标行动结算最大气血 4%/5%；虚弱减少攻击伤害 20%，破甲减少防御 30%。净化消除灼烧、标记、虚弱、破甲。状态不会复活已阵亡单位。

完整英雄与器物规则表见 [BUILD_GUIDE.md](BUILD_GUIDE.md)。

## 五人阵容与真实羁绊

前排两人、后排三人，五名不能重复；选已有出战神仙会交换阵位。布阵页可按已拥有英雄一键组成指定阵营的五职业阵容，缺职业时明确提示，不会自动赠卡或偷偷抽卡。

- 同阵营 3/5 人：全队攻击与气血 +8%/+14%。
- 云阙金身：3/5 人额外防御 +8%/+15%。月华回生：额外治疗 +8%/+15%。山海战意：额外暴击率 +4/+8 个百分点。
- 五职同心：五种职业齐全，全队气血 +5%。
- 人物组合：八仙同游、封神战友、广寒相伴、幽冥巡司、四象镇世、补天画卦。布阵页显示已组成的数量及实际激活效果。加成进入战斗属性与治疗/暴击计算，非仅展示。

御守提供护盾和嘲讽，剑修前排爆发，术法群伤，医仙治疗，影袭优先后排。通常每两次普通行动后释放该英雄的专属绝技，充能和灵力削减会改变时机；速度决定行动顺序，同速随机。最大30回合，先比较存活数，再比较剩余气血比例和。双方使用同一规则。72 位英雄各有一套独立配置的专属绝技（目标、倍率与效果序列），叠加 12 类英雄被动和器物技能。共享伤害、治疗、状态等底层规则，技能说明直接从实际执行配置生成。

24 个机器人按出战队伍与最近战绩动态调整，双方均受仙府同等基础加成，战斗开始后属性固定。排行采用 Elo，每周一北京时间零点换季；队伍成长和仙府永久保留。

## 明确的等级路线

英雄初始等级上限20，每通关5次历练增加5级，最终100。详情展示“当前等级 / 当前上限 / 最终上限”、还需通关次数、升级进度条。可免费升1级或直接升至当前上限。累积同名招募2/4/7/11/16次，依次解锁1–5星，不消耗已有卡牌。

## 仙府核心循环

**神仙收集与派驻 → 修行心得 → 仙府突破 / 炼丹炼器 → 五人战斗 → 历练解锁更高建筑与培养上限**。

- 百草灵圃、神工炼器阁、万法藏经楼：每座建筑初始1级，每五次历练通关增加1级上限，最高10。升级免费。医仙/御守/术法对应派驻时每分钟额外产出2心得，其余职业额外1；一位神仙只能派驻一处，仍可出战。更换派驻、升级前按旧速率结算。
- 离线修行：按实际时长与每分钟速率积累心得，领取整数部分并保留零头；速率由建筑等级之和及派驻加成决定，最多结算24小时，点击领取不可重复。心得是修行记录，不是付费货币；主动参悟每次免费得30，可无限进行，无需等待才能推进。
- 仙府突破：当前等级×60心得，每重增加全队攻击/气血1%；同样受历练上限约束，最高10重。
- 炼丹：九转灵丹每重永久全队气血+1%，材料无限，最高10重，历练解锁上限。
- 炼器：镇岳剑每重攻击+2%；护心钟每重气血+2.5%；玄光镜每重防御+3%。免费精炼，最高10重，历练解锁上限。一次只能佩用一件，全队生效。
- 洞天秘境：派出当前队伍的投影探索1分钟，离线后也可领取60+仙府等级×10心得、英雄十连及天命印，不影响正常出战。完成后领取一次、继续探索。
- 既有五人历练、每日仙约、永久累计的无尽通天塔、阵容PK、赛季排行继续可玩。探索计时和周期基于设备时间，无真人服务器校时。

## 开发、构建、自检

Node.js >=20，Python3 用于打包。生产包无第三方网络资源或运行时服务。

```sh
npm ci --cache /workspace/.cache/npm --no-audit --no-fund
npm run build
npm start
npm test
BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:browser
node tests/v5-browser.mjs
node tests/v6-browser.mjs
node tests/armory-browser.mjs
node tests/deployment.mjs
python3 scripts/package.py
cp dist/one-leaf-web.zip releases/one-leaf-web.zip
```

`npm start` 默认3000，可设置 PORT。测试自行启动3100/3113/3101端口。浏览器测试需 Chromium，v5 与部署测试默认 `/usr/bin/chromium`。WebKit/实体 iPhone 尚未验证，详情见 [VALIDATION.md](VALIDATION.md)。

- `src/techniques.js`：72 套专属绝技与统一的规则说明生成。
- `src/heroes.js`：72神仙、出处、羁绊、战斗引擎。
- `src/squad.js`：抽卡、养成、竞技、活动、版本迁移。
- `src/relic-pool.js`：神兵/法宝池、装备、联动描述与存档校验。
- `src/estate.js`：建筑、派驻、离线修行、炼丹炼器、探索。
- `src/vault.js`：快照、IndexedDB、恢复与写入保护。
- `src/squad-app.js`、`src/immortal.css`、`src/gacha.css`、`src/armory.css`：当前UI与交互。
- `scripts/build.mjs`：生成 public/game.js、game.css 和 play.html；修改源码后必须重建。
- `src/game.js`、`src/app.js`：保留的旧版源码，不是当前入口。

本地开发地址不能当作手机公网试玩地址；目前没有托管账户配置，需把完整 ZIP 部署到你的现有站点。
