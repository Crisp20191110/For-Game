# 一叶问仙

原创青绿山水风格的轻量修仙游戏。借鉴装备收集与放置养成这一玩法类型，未使用《寻道大千》的名称、美术或代码。适配 iPhone Safari，可添加到主屏幕作为 PWA 游玩。

## 下载现成部署包

仓库内已附带 [one-leaf-web.zip](releases/one-leaf-web.zip)。打开该文件页面，选择 **Download raw file** 下载，解压后即可上传到 HTTPS 静态托管站点的根目录。它只包含游戏网页资源，无需安装 Node.js 或执行构建。

修改游戏后运行 `python3 scripts/package.py`，再将生成的 `dist/one-leaf-web.zip` 复制到 `releases/one-leaf-web.zip`，以更新随仓库分发的部署包。

## v3.0 · 群仙结阵

核心玩法已改为 **无限抽卡 → 英雄收集与养成 → 五人编队 → 动态机器人队伍 PK**。无需账号，首次完整缓存后离线可玩，没有充值或真人联网功能。

### 抽卡与英雄

- 18 名原创中国仙侠英雄，三个阵营：云阙、月华、山海。
- 三种稀有度：R 灵品、SR 仙品、SSR 神品。基础概率分别为 70%、25%、5%；同稀有度内英雄等概率。
- 每 10 抽内至少得到 SR 或 SSR，每 50 抽内必得 SSR；单抽、十连共用并保存保底计数。SR/SSR 重置十抽计数，SSR 同时重置五十抽计数。上述为基础概率，保底触发时对应档位概率提高。
- 灵玉、招募券、培养材料和挑战次数无限。初始赠送五位不同职业的 R 英雄，立即可出战。
- 英雄升级至当前上限免费；每通关 5 次历练，等级上限提升 5 级，从 20 级逐步升至 100 级。
- 同名招募累计 2、4、7、11、16 次可依次觉醒至 1–5 星。不扣除英雄或招募记录。星级属于收集成长目标，不是付费材料。

### 五人阵容和战斗

- 每队必须是五名不同英雄，前排两人、后排三人。点击阵位后选人；选到已经出战的英雄时交换位置。
- **御守**：全队护盾、嘲讽；**剑修**：前排单体爆发；**术法**：全体攻击；**医仙**：普通行动单体治疗、绝技全体治疗；**影袭**：优先攻击后排、绝技穿透部分防御。
- 同阵营三人，全队攻击和气血 +8%；五人 +14%。更高稀有度有属性优势，但阵位、职业和羁绊也会改变结果。
- 速度决定行动次序，同速随机先后；两次普通行动后施放绝技。双方遵循同一规则，阵亡英雄不能继续行动或被普通治疗复活。
- 对战最长 30 回合。若仍未全灭，先比较存活人数，再比较每名英雄剩余气血比例总和；完全相同则平局。
- 战斗支持逐行动展示、跳过动画和每名英雄的伤害/治疗战报。

### 机器人、排行与活动

- 8 位明确标注为机器人的仙盟，各有五人阵容与职业组合。
- 机器人等级随你的出战队伍平均等级、近期八场胜负逐步适配；星级也参考你的阵容。开始战斗后阵容及属性固定，刷新页面不重置对手或排行。
- 胜负按 Elo 改变积分；其他机器人在你完成对局后小幅改变积分。每周一北京时间 00:00 重置赛季，保留上一期名次及队伍成长。
- 五人历练解锁培养上限；每日签到、招募、历练、PK 委托；每周十层通天塔和成长成就。全部使用五人战斗规则。
- 声望只是成就记录，不是消耗货币。日/周刷新依赖设备时间，不是服务器活动。

### 旧存档与升级

v3 使用独立存档键 `one-leaf-squad-v3`，不会删除 v1/v2 的 `one-leaf-immortal-v1`。首次打开若发现旧存档，会给五位初始英雄折算 `旧境界索引 + 1` 级，最多 20 级，并保留旧境界、关卡摘要。旧版个人装备、灵树及单人排名不直接套入新的队伍系统，新版历练从第 1 关开始。

1. 更新前在旧版菜单导出备份。
2. 用最新部署包覆盖原 HTTPS 站点，保留网址，不要清理网站数据。
3. 若旧页面提示新版已就绪，打开手记选择保存并更新；也可关闭该站点的所有页面及主屏幕应用再重开。
4. 新版手记可导出阵容存档、导入 v1/v2/v3 存档，以及导出保留的旧修行原件。跨设备时使用 JSON 备份迁移。

本版是可玩的离线五人卡牌原型：英雄以简化原创矢量形象展示，同职业共享基础技能机制，后续可以继续扩展独立英雄技能、特效、更多卡池和剧情。实体 iPhone / Safari 尚未验证。

## 本地运行

需要 Node.js 20 或以上。运行游戏没有第三方运行时依赖，不需要先安装 npm 包：

```sh
cd /workspace/For-Game
npm start
```

默认端口为 3000，可用 `PORT=8080 npm start` 修改。开发服务器监听全部网卡，只公开游戏文件，不公开 Git 元数据或测试文件。不要直接双击 HTML 文件，ES Modules 和离线缓存需要 HTTP 服务。

## 在 iPhone 上游玩

### 同一局域网快速体验

在你自己的电脑运行以上命令，让 iPhone 和电脑连接同一 Wi-Fi，然后在 Safari 访问 `http://电脑的局域网IP:3000`。若系统防火墙阻止访问，允许该端口的本地网络访问。**普通局域网 HTTP 可以玩，但不支持 Service Worker 离线缓存。云开发机的本地地址并不能直接在手机打开。**

### 通过 HTTPS 网址游玩（推荐）

把下列文件部署到支持 HTTPS 的静态托管站点根目录即可，例如 Cloudflare Pages 或 Netlify 的静态站点部署；无需后端或构建命令：

```text
index.html
manifest.webmanifest
sw.js
src/squad-app.js
src/squad.js
src/heroes.js
src/style.css
src/cards.css
public/*
```

也可以用 `python3 scripts/package.py` 生成 `dist/one-leaf-web.zip`（压缩包内容就是站点根目录）。不包含测试、Node 依赖或 Git 信息。路径以 `/` 开头，因此须部署在域名根目录；若放在 GitHub Pages 项目子路径，需另行适配路径。

1. 用 iPhone Safari 打开部署后的 HTTPS 网址。
2. 等待首次页面加载完成，点击一次祈愿体验游戏。
3. Safari 分享菜单 → **添加到主屏幕**。
4. 从主屏幕启动，体验接近独立 App 的全屏效果。成功完成首次缓存后即可断网游玩。

存档属于当前浏览器/站点，换域名、清理网站数据或更换手机不会自动迁移。添加到主屏幕前建议在右上角菜单中导出备份，再在独立应用中导入。无痕模式或存储限制可能影响进度保存。建议使用 iOS 16.4 或更新版本。

本仓库没有配置托管账号，尚未发布公网网址。要做 TestFlight 原生包，还需要后续封装、Apple Developer 账号和签名流程。

## 验证

核心规则测试（不需要安装依赖）：

```sh
npm test
```

浏览器测试：

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

若系统已有 Chromium，可跳过浏览器下载：

```sh
BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:browser
```

也支持 `npx playwright install webkit` 后使用 `BROWSER=webkit npm run test:browser`。Linux 可能还需要 Playwright 的系统依赖；WebKit 自动化通过也不能替代实体 iPhone 验证。

浏览器实际执行 50 抽保底、职业筛选、升级觉醒、五人换位、机器人 PK、历练/塔、领奖、存档往返、离线抽卡与对战、日/周刷新、旧版迁移、版本更新和六种视口检查。截图输出到被 Git 忽略的 `test-results/`。

## 开发结构

- `src/heroes.js`：原创英雄配置、属性、羁绊与共享五人战斗引擎。
- `src/squad.js`：抽卡保底、英雄养成、阵容、机器人、排行、活动与存档迁移。
- `src/squad-app.js`、`src/cards.css`：手机页面、招募展示、阵容编辑和战斗回放。
- `src/style.css`：通用青绿主题样式；`public/`：原有场景与图标。
- `src/game.js`、`src/app.js`：保留的 v2 单人玩法源码，不作为 v3 页面入口，也不打入新版静态部署包。
- `sw.js`：完整应用壳离线缓存。每次发布修改缓存版本，并验证旧缓存升级与进度保留。

运行 `npm test` 执行 v2 的 19 项回归测试和 v3 的 16 项阵容/抽卡/战斗测试。`npm run test:browser` 针对当前 v3 页面。
