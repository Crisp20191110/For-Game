# 一叶问仙

原创青绿山水风格的轻量修仙游戏。借鉴装备收集与放置养成这一玩法类型，未使用《寻道大千》的名称、美术或代码。适配 iPhone Safari，可添加到主屏幕作为 PWA 游玩。

## 下载现成部署包

仓库内已附带 [one-leaf-web.zip](releases/one-leaf-web.zip)。打开该文件页面，选择 **Download raw file** 下载，解压后即可上传到 HTTPS 静态托管站点的根目录。它只包含游戏网页资源，无需安装 Node.js 或执行构建。

修改游戏后运行 `python3 scripts/package.py`，再将生成的 `dist/one-leaf-web.zip` 复制到 `releases/one-leaf-web.zip`，以更新随仓库分发的部署包。

## v2.0 · 无尽仙途

- **无限资源**：灵石、灵露、修为、材料与挑战次数均无限，不扣除余额、不等待恢复。声望、图鉴和段位只是成长记录，不是消耗货币。
- **成长路线**：六章目标、八境循环后的重天进阶；通过历练解锁下一境和培养上限。每个重天有八境，当前实现支持到第 9999 次境界进阶，非数学上的无限数值。
- **三种流派**：逍遥均衡、剑修偏攻击与会心、玄甲偏生存，随时免费切换。
- **装备养成**：五种品质、三种部位、15 项图鉴；十连祈愿按当前流派总战力自动择优，不自动穿戴更弱装备。
- **机器人仙榜**：8 位有名字、流派和强弱梯度的机器人，明确标注为本地模拟对手。与玩家一起按 Elo 积分排序，周赛季结算，至少打 5 场且前三可获得称号。
- **动态适配**：对局开始时锁定双方属性，结束后缓慢向玩家的战力靠近，并参考最近 8 场战绩调整压力。升级后仍有领先空间，连败后压力降低；刷新页面不重新随机对手。其他机器人的积分只在你完成对局后小幅变化。
- **每日活动**：签到、20 次祈愿、3 次历练、3 场论道，奖励声望；累计签到 7 天得称号。
- **每周活动**：十层试炼塔、十二回合木灵首领伤害挑战，以及仙榜赛季。试炼基准在每周开始时固定，玩家成长不会让当周敌人同步升级。
- **收藏与成就**：章节奖励、图鉴全收集、论道十胜、试炼塔、首领和赛季称号。
- **存档与离线**：自动迁移 v1 存档并保留原件；支持 JSON 备份、异常存档导出与多窗口覆盖保护。HTTPS 首次缓存完成后可离线操作全部玩法。

所有每日活动于北京时间 00:00 刷新；每周活动与赛季于周一 00:00 刷新。换周会重置活动和竞技积分，保留装备、境界、声望、永久称号及上一赛季战报。离线跨周期在下次打开时处理。电脑时钟决定本地活动周期，不具备服务器防作弊能力。

这是单机游戏与机器人联赛，没有充值、广告、真人联网排行、云端同步或原生 iOS 安装包。实体 iPhone / Safari 仍待验证。

### 如何从第一版升级

1. 先在旧版右上角菜单导出存档，留作备份。
2. 下载最新 `releases/one-leaf-web.zip`，覆盖部署到原来的 HTTPS 网址，不必换域名。
3. 联网重开游戏；若手记提示新版已就绪，选择“保存进度并更新游戏”。若旧页面未出现入口，关闭该网站所有页面和主屏幕应用，再重新打开。
4. 不要清理网站数据。原有境界、装备、历练和章节领取状态会迁移，资源自动切到无限。换域名或浏览器时通过导入存档迁移。

## 本地运行

需要 Node.js 20 或以上。运行游戏没有第三方运行时依赖，不需要先安装 npm 包：

```sh
cd /workspace/For-Game
npm start
```

默认端口为 3000，可用 `PORT=8080 npm start` 修改。开发服务器监听全部网卡，只公开游戏文件，不公开 Git 元数据或测试文件。不要直接双击 HTML 文件，ES Modules 和离线缓存需要 HTTP 服务。

## 在 iPhone 上游玩

### 同一局域网快速体验

在你自己的电脑运行以上命令，让 iPhone 和电脑连接同一 Wi-Fi，然后在 Safari 访问 `http://电脑的局域网IP:3000`。若系统防火墙阻止访问，允许该端口的本地网络访问。**普通局域网 HTTP 可以玩，但不支持 Service Worker 离线缓存。云开发机的本地地址并不能直接在手机打开。**

### 通过 HTTPS 网址游玩（推荐）

把下列文件部署到支持 HTTPS 的静态托管站点根目录即可，例如 Cloudflare Pages 或 Netlify 的静态站点部署；无需后端或构建命令：

```text
index.html
manifest.webmanifest
sw.js
src/app.js
src/game.js
src/style.css
public/*
```

也可以用 `python3 scripts/package.py` 生成 `dist/one-leaf-web.zip`（压缩包内容就是站点根目录）。不包含测试、Node 依赖或 Git 信息。路径以 `/` 开头，因此须部署在域名根目录；若放在 GitHub Pages 项目子路径，需另行适配路径。

1. 用 iPhone Safari 打开部署后的 HTTPS 网址。
2. 等待首次页面加载完成，点击一次祈愿体验游戏。
3. Safari 分享菜单 → **添加到主屏幕**。
4. 从主屏幕启动，体验接近独立 App 的全屏效果。成功完成首次缓存后即可断网游玩。

存档属于当前浏览器/站点，换域名、清理网站数据或更换手机不会自动迁移。添加到主屏幕前建议在右上角菜单中导出备份，再在独立应用中导入。无痕模式或存储限制可能影响进度保存。建议使用 iOS 16.4 或更新版本。

本仓库没有配置托管账号，尚未发布公网网址。要做 TestFlight 原生包，还需要后续封装、Apple Developer 账号和签名流程。

## 验证

核心规则测试（不需要安装依赖）：

```sh
npm test
```

浏览器测试：

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

若系统已有 Chromium，可跳过浏览器下载：

```sh
BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:browser
```

也支持 `npx playwright install webkit` 后使用 `BROWSER=webkit npm run test:browser`。Linux 可能还需要 Playwright 的系统依赖；WebKit 自动化通过也不能替代实体 iPhone 验证。

浏览器检查无限资源、十连、流派、成长、机器人对战及排名、活动领奖、首领与试炼、跨日/跨周刷新、旧版迁移、备份恢复、多窗口保护、断网操作与 320–1280px 布局。截图输出到被 Git 忽略的 `test-results/`。

## 开发结构

`src/game.js` 是纯规则层，`src/app.js` 负责界面与存储，`src/style.css` 负责响应式样式。`public/` 是原创矢量场景及图标。`sw.js` 提供离线缓存。发布应用壳更新时同步调整缓存版本；新版采用整套应用壳缓存，等待玩家保存进度后激活，避免新旧模块混用。
